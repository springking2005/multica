# 波笛智能体 启动指南

## 环境要求

| 组件 | 最低版本 | 用途 |
|------|------|------|
| Python | 3.12+ | 运行环境 |
| PostgreSQL | 17 + pgvector 扩展 | 生产数据库 |
| Redis | 7+ | WebSocket channel layer + Celery |
| Git | 2.40+ | 代码仓库操作 |
| Docker | 24+ | 容器化部署（可选） |
| AI CLI 工具 | 至少一种 | agent 执行（见下方） |

**支持的 AI CLI 工具**（至少安装一种）：
- Claude Code (`claude`)
- Codex (`codex`)
- GitHub Copilot CLI (`copilot`)
- OpenClaw (`openclaw`)
- OpenCode (`opencode`)
- 其他：Hermes, Gemini, Pi, Cursor, Kimi, Kiro

## 一、开发环境启动（本地）

### 1.1 克隆项目

```bash
git clone https://github.com/springking2005/multica.git
cd multica/bodiagent
```

### 1.2 安装 Python 依赖

```bash
pip install -e ".[dev]"
```

### 1.3 配置环境变量

```bash
cp .env.example .env
# 编辑 .env，修改必要配置
```

开发环境（`settings_dev.py`）默认使用 SQLite + 内存 Redis，无需额外配置即可运行。

### 1.4 初始化数据库

```bash
python manage.py migrate
```

### 1.5 创建管理员账号

```bash
python manage.py createsuperuser
# 输入邮箱和密码
```

### 1.6 启动开发服务器

```bash
python manage.py runserver 0.0.0.0:8000
```

访问 http://localhost:8000/ 进入登录页。

### 1.7 运行测试

```bash
# 运行所有测试
python -m pytest -q

# 运行单个模块
python -m pytest accounts/ -v

# 契约校验
python scripts/validate_contracts.py

# 浏览器端到端测试（Playwright/Chromium；覆盖前端路由 + e2e/specs）
# e2e 使用 Django live_server，需关闭 xdist 以避免 SQLite/live_server 并发干扰。
python -m pytest -q bodiagent/tests/test_frontend_routes.py e2e/specs -q -n 0
```

## 二、Docker Compose 启动（完整开发环境）

### 2.1 启动全部服务

```bash
docker compose up -d
```

启动后包含：
- PostgreSQL 17 + pgvector (端口 5432)

### 2.2 查看日志

```bash
docker compose logs -f web
```

### 2.3 停止服务

```bash
docker compose down
```

## 三、生产环境部署

### 3.1 构建镜像

```bash
# 服务端镜像
docker build -t bodiagent-server -f Dockerfile .

# Daemon CLI 镜像
docker build -t bodiagent-daemon -f Dockerfile.daemon .
```

### 3.2 配置生产环境变量

创建 `.env.production`：

```bash
DJANGO_SECRET_KEY=<生成一个强随机字符串>
ALLOWED_HOSTS=your-domain.com,www.your-domain.com
CORS_ALLOWED_ORIGINS=https://your-domain.com

POSTGRES_DB=bodiagent
POSTGRES_USER=bodiagent
POSTGRES_PASSWORD=<强密码>
POSTGRES_HOST=db

REDIS_URL=redis://redis:6379/0

FROM_EMAIL=noreply@your-domain.com
SMTP_HOST=smtp.your-provider.com
SMTP_PORT=587
SMTP_USER=<邮箱账号>
SMTP_PASSWORD=<邮箱密码>

# 可选：阿里云 OSS 文件存储
DJANGO_STORAGE_BACKEND=storages.backends.s3boto3.S3Boto3Storage
AWS_ACCESS_KEY_ID=<key>
AWS_SECRET_ACCESS_KEY=<secret>
AWS_S3_BUCKET_NAME=bodiagent-uploads
AWS_S3_ENDPOINT_URL=https://oss-cn-hangzhou.aliyuncs.com

# 可选：Sentry 错误追踪
SENTRY_DSN=https://xxx@sentry.io/xxx
```

### 3.3 启动生产环境

```bash
# 导出环境变量
export $(cat .env.production | xargs)
export DJANGO_SETTINGS_MODULE=bodiagent.settings_prod

# 迁移数据库
python manage.py migrate

# 收集静态文件
python manage.py collectstatic --noinput

# 启动（gunicorn + uvicorn worker，支持 WebSocket）
gunicorn bodiagent.asgi:application \
  -k uvicorn.workers.UvicornWorker \
  -b 0.0.0.0:8000 \
  -w 4
```

### 3.4 反向代理（Nginx 示例）

```nginx
server {
    listen 443 ssl;
    server_name bodiagentteam.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto https;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /ws/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }

    location /static/ {
        alias /path/to/bodiagent/staticfiles/;
    }
}
```

### 3.5 Celery Worker（定时自动化）

```bash
# 单独启动 Celery worker
celery -A bodiagent worker -l info

# Celery beat（周期任务调度）
celery -A bodiagent beat -l info
```

## 四、安装 Daemon CLI

daemon CLI 运行在你的开发机上，负责连接服务器、领取并执行 AI 任务。

### 4.1 安装

```bash
cd bodiagent/daemon_cli
pip install -e .
```

安装后可用命令：`bodiagent-daemon`

### 4.2 配置

```bash
bodiagent-daemon setup
```

交互式配置：
1. 输入服务器地址（如 `https://bodiagentteam.com`）
2. 输入认证 token（从 Web 端 Settings → Tokens 获取）
3. 选择工作区

配置文件存储在 `~/.bodiagent/config.json`。

### 4.3 启动 daemon

```bash
# 前台运行（调试用）
bodiagent-daemon start --foreground

# 后台运行
bodiagent-daemon start
```

### 4.4 管理 daemon

```bash
bodiagent-daemon status    # 查看状态
bodiagent-daemon stop      # 停止
bodiagent-daemon restart   # 重启
bodiagent-daemon version   # 版本信息
bodiagent-daemon update    # 自更新
```

### 4.5 多环境（Profile）

```bash
# 创建 staging 环境配置
bodiagent-daemon setup --profile staging

# 启动 staging daemon（独立端口、独立工作目录）
bodiagent-daemon start --profile staging
```

## 五、首次使用指南

### 5.1 创建账号并登录

1. 访问 http://localhost:8000/register
2. 输入姓名、邮箱、密码
3. 输入验证码（开发环境固定为 `888888`）

### 5.2 创建工作区

1. 登录后进入 dashboard
2. 点击"创建工作区"
3. 填写名称和 slug（3 字母前缀，用于 issue 编号，如 `BOD-123`）

### 5.3 注册 Daemon

1. 在开发机上安装并启动 daemon CLI（见第四章）
2. 在 Web 端进入 Settings → Runtimes，确认 daemon 已出现

### 5.4 创建 Agent

1. 进入 Agents 页面
2. 点击"新建 Agent"
3. 选择 daemon、Provider（如 claude）、模型
4. 填写名称和指令
5. 保存

### 5.5 创建第一个 Issue

1. 进入 Issues 看板
2. 点击"新建 Issue"
3. 填写标题、描述、优先级
4. 将负责人设为刚创建的 Agent
5. 提交 — Agent 自动开始工作

### 5.6 查看 Agent 执行进度

1. 打开 Issue 详情页
2. 在活动时间线中查看实时进度
3. Agent 的思考过程、工具调用、代码变更加以展示
4. 执行完成后 Agent 会自动发表评论并变更状态

## 七、故障排查

| 问题 | 检查项 |
|------|------|
| `pip install` 失败 | Python 版本 >= 3.12？`python3 --version` |
| `manage.py check` 报错 | 是否在 bodiagent/ 目录下执行？ |
| 登录后无法创建 workspace | daemon 是否启动？agent 是否绑定？ |
| agent 不接任务 | daemon 状态是否 online？在 Settings → Runtimes 确认 |
| daemon 报连接错误 | server URL 是否正确？防火墙是否放行 WebSocket 端口？ |
| 测试中 JWT 警告 | 开发环境 SECRET_KEY 长度不足，生产环境更换强密钥即可 |
| 迁移冲突 | 只一个开发者有权创建迁移，其他人 `python manage.py migrate --run-syncdb` |
| WebSocket 连接失败 | Redis 是否启动？生产环境需配置 channel layer |
