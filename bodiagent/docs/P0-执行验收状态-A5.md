## 人工验收清单

P0 完成前必须人工确认：

- 浏览器登录后可完成 Chat 会话：创建 session、发送消息、看到广播/回复。
- 两个浏览器或两个 WS 客户端加入同一 Chat session 后可互收消息。
- 未登录、无权限 session、非法 UUID、断线重连/断开处理符合预期。
- Chat 输入内容按文本显示，不执行 HTML/Script。
- Agent、Project、Autopilot、CLI Token 页面可完成创建、编辑、删除或生成。
- 375px 宽度下 Chat、表单、弹窗、侧边栏、长文本不遮挡。
- Docker compose 环境下 `/health/` 返回 200。
- PostgreSQL 环境下 migrate、fixtures、pytest 通过。
- 至少一个真实 AI CLI 完成接任务、执行、回传结果。
- SMTP 真实邮件发送成功，Sentry 能看到异常事件，生产日志为 JSON stdout。
